# Retribución variable del comité de dirección

Documento ficticio de acceso restringido. Solo debe recuperarse para el grupo «direccion».

## Objetivos

El variable del comité de dirección se calcula con tres objetivos: margen operativo, satisfacción de clientes y cumplimiento del plan de seguridad. Cada objetivo pesa un tercio.

## Pago

El variable se paga en marzo del año siguiente, una vez auditadas las cuentas.
